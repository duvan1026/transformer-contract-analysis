# Plan de trabajo — Hito 1

Transformación de CUAD en dataset de clasificación de spans

## Objetivo del hito

Transformar el dataset CUAD en un conjunto de datos estructurado para clasificación supervisada de fragmentos de texto y entrenar un baseline Transformer evaluado con métricas reproducibles.

Duración estimada: **5 semanas**
Dedicación: **~10 horas semanales**

---

## Semana 1 — Exploración y definición taxonómica

### Objetivos

Comprender la estructura interna del dataset y definir formalmente la taxonomía de cláusulas.

### Tareas

* Explorar la estructura de archivos del dataset
* Analizar el formato de anotaciones (spans y offsets)
* Seleccionar las cinco categorías objetivo
* Definir criterios operativos de cada cláusula
* Documentar la taxonomía

### Entregables

* Documento de definición taxonómica
* Script exploratorio del dataset
* Notas técnicas sobre estructura de CUAD
